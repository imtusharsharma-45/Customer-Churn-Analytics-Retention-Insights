# Customer Churn Analysis

## Project Overview
This project analyzes customer churn behavior using Python, Pandas, Seaborn, Matplotlib, SQL, and Power BI.

The goal is to identify key reasons why customers leave the company.

---

## Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- SQL
- VS Code

---

## Key Insights

- Month-to-month customers have highest churn
- Customers with higher monthly charges tend to leave more
- Low tenure customers churn more frequently
- Fiber optic users show higher churn
- Electronic check users show higher churn
